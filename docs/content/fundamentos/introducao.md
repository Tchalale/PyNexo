# Introdução ao Python

## O que é Python?

Python é uma linguagem de programação de alto nível, interpretada e de propósito geral. É conhecida pela sua sintaxe simples e legibilidade, permitindo desenvolver diferentes tipos de aplicações.

Python é utilizado em áreas como:

- Desenvolvimento web.
- Inteligência Artificial.
- Ciência de dados.
- Automação de tarefas.
- Desenvolvimento de aplicações.
- Cibersegurança.
- Computação científica.

## Por que aprender Python?

Python possui uma sintaxe relativamente simples, uma comunidade activa e um vasto ecossistema de bibliotecas.

É uma linguagem adequada tanto para quem está a dar os primeiros passos na programação como para profissionais experientes.

## Como funciona Python?

O código Python é escrito em ficheiros com extensão `.py` e executado através do interpretador Python.

Exemplo:

```python
print("Olá, mundo!")
```

O resultado será:

```text
Olá, mundo!
```
