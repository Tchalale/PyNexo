# O teu primeiro programa em Python

Chegou o momento de escrever e executar o teu primeiro código Python.

## 1. Criar um ficheiro

Cria um ficheiro chamado `ola.py`.

## 2. Escrever o código

```python
print("Olá, mundo!")
```

## 3. Executar o programa

Abre o terminal na pasta onde guardaste o ficheiro e executa:

```bash
python ola.py
```

Resultado:

```text
Olá, mundo!
```

## 4. Compreender o código

A função `print()` permite apresentar informações no ecrã.

Neste exemplo, estamos a apresentar uma mensagem de texto.

## 5. Experimenta

Altera a mensagem:

```python
print("Estou a aprender Python com o PyNexo!")
```
