# Como contribuir para o PyNexo

Antes de mais, obrigado pelo teu interesse em contribuir para o PyNexo!

O PyNexo é uma biblioteca aberta de conhecimento sobre Python em língua portuguesa. O seu crescimento depende da participação de pessoas que queiram aprender, ensinar e partilhar conhecimento.

Não precisas de ser especialista em Python para contribuir. Todas as contribuições construtivas são bem-vindas.

## Formas de contribuir

Podes participar de várias formas:

- Criar tutoriais sobre Python.
- Explicar conceitos da linguagem.
- Partilhar exemplos práticos de código.
- Documentar bibliotecas Python.
- Apresentar boas práticas de programação.
- Desenvolver projectos demonstrativos.
- Criar guias para iniciantes.
- Corrigir erros e melhorar conteúdos existentes.
- Sugerir novos temas para a biblioteca.

## Como enviar uma contribuição?

Segue estes passos:

### 1. Explora o repositório

Consulta os conteúdos existentes para conhecer a organização da biblioteca e evitar duplicações.

### 2. Escolhe o que pretendes contribuir

Podes melhorar um conteúdo existente ou propor um novo material.

### 3. Faz uma cópia do repositório

No GitHub, utiliza a opção **Fork** para criar uma cópia do PyNexo na tua conta.

### 4. Desenvolve a tua contribuição

Cria ou altera os ficheiros necessários. Procura manter os conteúdos organizados e fáceis de compreender.

### 5. Envia uma proposta de alteração

Quando terminares, cria um **Pull Request** para apresentar as tuas alterações ao projecto.

A equipa responsável irá analisar a contribuição e poderá solicitar ajustes antes da aprovação.

## Orientações para os conteúdos

Para manter a qualidade da biblioteca, pedimos que:

- Os conteúdos sejam escritos em língua portuguesa.
- As explicações sejam claras e acessíveis.
- Os exemplos de código sejam funcionais e, sempre que possível, testados.
- O código esteja devidamente formatado.
- Os materiais sejam originais ou tenham autorização para publicação.
- As fontes externas sejam identificadas quando utilizadas.
- Os conteúdos sejam úteis para quem está a aprender ou aprofundar Python.

## Qualidade das contribuições

Todas as contribuições devem procurar respeitar os princípios de clareza, organização, precisão e partilha de conhecimento.

O objectivo não é produzir conteúdos perfeitos à primeira tentativa, mas construir uma biblioteca cada vez melhor através da colaboração.

## Tens uma ideia?

Se tens uma sugestão, identificaste um problema ou gostarias de propor um novo conteúdo, podes abrir uma [Issue](../../issues) no GitHub.

A tua ideia pode ser o início de uma nova contribuição para o PyNexo.
